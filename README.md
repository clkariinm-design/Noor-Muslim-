# Noor Muslim

This repository currently contains an intentionally empty Android application shell.

The previous application features and their bundled data have been removed from this reset branch. There are no Quran assets, offline caches, audio files, prayer features, screens, app data repositories, remote API clients, or backend source code in this version.

The launcher activity opens to an empty screen. The Android project structure and build workflow remain so a new application can be built from this clean starting point.

## Build

The GitHub Actions workflow builds a debug APK with Gradle and Android SDK 36.1.
